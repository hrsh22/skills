# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security** tab using a private vulnerability report. Do not include secrets, private repository content, access tokens, or sensitive transcripts in a public issue.

Include the affected skill or plugin version, the smallest reproducible prompt or file set, the observed behavior, and the expected security boundary. You can expect an acknowledgement within seven days.

## Scope

Agent skills are executable instructions. Review every skill before installing it and run agents with permissions appropriate to the task. This project does not grant an agent authority beyond the host's sandbox, approval policy, or the user's request.

Only the latest release is supported with security fixes during the `0.x` series.
